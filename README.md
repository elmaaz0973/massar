# منصة التعلم الذاتي – البكالوريا (ICT / البرمجة والذكاء الاصطناعي)

MERN: MongoDB + Express + React (Vite) + Node. واجهة عربية RTL.

## التشغيل
```bash
npm run install:all
cp server/.env.example server/.env   # املأ JWT_SECRET (مثلاً: openssl rand -hex 32) وعدّل MONGODB_URI عند الحاجة
npm run seed                         # تحميل هيكل المراحل والوحدات والدروس
npm run create:admin -- you@example.com "اسمك"   # إنشاء حساب الإدارة (يطلب كلمة المرور)
npm run import:content               # استيراد الدروس الجاهزة من server/seed/content (أضف --force للكتابة فوق الموجود)
npm run dev                          # الواجهة: :5173  |  الـ API: :5000
```

## منهجية المحتوى (مهم)
المحتوى مرجع لطالب سيُمتحن، لذلك **ممنوع نشر أي درس لم يُطابَق بالكتاب**. اقرأ `CONTENT-REVIEW.md` أولاً.
- `npm run coverage` — ما تم وما تبقى (من 85 درساً).
- `npm run check:content` — بوابة جودة: لكل درس مرجع صفحات، ولكل سؤال كويز رقم صفحة.
- `npm run seed -- --prune` — يحذف الوحدات والدروس القديمة التي لم تعد في الهيكل (بشرط ألا يكون لها محتوى).
- ترقيم الدروس يتبع الكتاب: الصف الأول «رقم الدرس-رقم الوحدة»، والصف الثاني «رقم الوحدة-رقم الدرس». الـ slug الداخلي دائماً `lesson-<وحدة>-<درس>`.

## لوحة التحكم
سجّل الدخول بحساب الإدارة (أنشئه بأمر `create:admin`) ثم افتح `/admin`. التسجيل العام ينشئ حسابات طلاب فقط.
لإضافة درس أو كويز عبر ملفات: ضع `server/seed/content/<stage-slug>/<lesson-slug>.md` و`<lesson-slug>.quiz.json` بالصيغة الموجودة في الأمثلة ثم شغّل `npm run import:content`.

## ملاحظة حقوق النشر
الكتب الرسمية ملك وزارة التربية والتعليم والتعليم الفني. الشروحات وأهداف التعلم تُكتب بصياغة المنصة، ولا تُنسخ نصوص الكتب.

## ملاحظات أمنية
- كلمات المرور تُخزَّن مُشفَّرة (bcrypt)، والجلسات JWT صالحة 30 يوماً، والتوكن يُحفظ في `localStorage`. المحتوى المعروض يُنظَّف من أي سكريبت، لكن عند النشر الفعلي يُفضَّل الانتقال إلى cookie من نوع httpOnly لو خدمتَ الواجهة والـ API من نفس النطاق.
- إجابات الكويز الصحيحة لا تغادر الخادم إلا بعد التصحيح.
- مسارات الدخول والتسجيل والإدارة عليها حد لمعدل الطلبات.

## الأدوات التفاعلية
- المنطق الحسابي لكل أداة في `client/src/tools/lib/` (دوال نقية)، والواجهات في `client/src/tools/*.jsx`.
- لإضافة أداة جديدة: أنشئ المكوّن، ثم سجّله في `client/src/tools/registry.js` مع الدروس المرتبطة به بالصيغة `stage-slug/lesson-slug`.
- محرر الويب يشغّل الكود داخل `iframe` بخاصية `sandbox="allow-scripts"` **بدون** `allow-same-origin`، مع سياسة CSP تمنع الاتصال بالشبكة، فلا يصل كود الطالب إلى حسابه أو توكن الجلسة.
