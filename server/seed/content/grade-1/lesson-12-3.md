## النقاط الرئيسية

### 1. هيكل الحلقة

**(1)** يتيح استخدام عبارة (for) تنفيذ عملية بشكل متكرر. تتم كتابة عبارة "for" كما يلي:

```python
for متغير in range(مدى المتغير):
    العملية المراد تكرارها
```

في عبارة (for)، يتم تنفيذ الأوامر البرمجية المسبوقة بمسافة بشكل متكرر.

**(2)** في عبارة (for)، يمكن استخدام ()range لتحديد مدى التكرار.

| طريقة الكتابة (Writing style) | المعنى (Meaning) |
|---|---|
| range(end value) | تزداد قيمة المتغير بمقدار 1، بدءًا من (0) وصولًا إلى (end value - 1). |
| range(start value, end value) | تزداد قيمة المتغير بمقدار 1، بدءًا من (start value) وصولًا إلى (end value - 1). |
| range(start value, end value, increment) | تزداد قيمة المتغير بمقدار (increment) المحدد، بدءًا من (start value) وصولًا إلى (end value - increment). |

مثال: برنامج يعرض الأعداد الصحيحة من 0 إلى 3

```python
for i in range(0, 4):   # كرر المتغير "i" بزيادة 1 من 0 إلى 3.
    print(i)            # يعرض قيمة المتغير "i".
```

نتيجة التنفيذ:

```
0
1
2
3
```

مثال: برنامج يعرض أرقامًا فردية من 1 إلى 5

```python
for i in range(1, 7, 2):   # كرر المتغير "i" بزيادة 2 من 1 إلى 6.
    print(i)               # يعرض قيمة المتغير "i".
```

نتيجة التنفيذ:

```
1
3
5
```

### 2. هيكل التفرع

**(1) (عامل المقارنة - Comparison operators):** عامل يستخدم لمقارنة التعبيرات أو القيم.

| عامل المقارنة | المعنى | مثال | معنى المثال |
|---|---|---|---|
| == | يساوي (Equal) | x == 70 | x تساوي 70 |
| != | لا يساوي (Not equal) | x != 70 | x لا تساوي 70 |
| < | أقل من (Less than) | x < 70 | x أقل من 70 |
| > | أكبر من (Greater than) | x > 70 | x أكبر من 70 |
| <= | أقل من أو يساوي (Less than or equal to) | x <= 70 | x أقل من أو تساوي 70 |
| >= | أكبر من أو يساوي (Greater than or equal to) | x >= 70 | x أكبر من أو تساوي 70 |

**(2)** يسمح استخدام عبارات (if) بتفرع الشروط ومعالجتها كتعبيرات شرطية.

- **(التعبير الشرطي - Conditional expression):** تعبير يحدد ما إذا كانت الشروط قد تم استيفاؤها وإرجاع "صحيح" إذا تم استيفاؤه و "خطأ" إذا لم يكن كذلك.

**[1]** استخدام (if ~ else) يجعل من الممكن وصف العملية التي تحدث عند عدم استيفاء الشرط.

```python
if تعبير شرطي:
    العملية عندما يكون الشرط صحيحًا
else:
    العملية عندما يكون الشرط خطأ
```

مثال: برنامج لتحديد النجاح أو الرسوب

```python
x = 70                  # تعيين القيمة 70 للمتغير x.
if x >= 60:             # إذا كانت x تساوي 60 أو أكبر،
    result = 'Pass'     # إذا كان الشرط صحيحًا، عيّن "Pass" للمتغير result.
else:                   # إذا لم يكن كذلك،
    result = 'Fail'     # عيّن "Fail" للمتغير result.
print(result)           # يعرض قيمة المتغير result.
```

نتيجة التنفيذ:

```
Pass
```

**[2]** استخدام (if ~ elif ~ else) يجعل من الممكن تحديد شروط متعددة بالتتابع.

```python
if تعبير شرطي 1:
    العملية عندما يكون التعبير الشرطي 1 صحيحًا
elif تعبير شرطي 2:
    العملية عندما يكون التعبير الشرطي 1 خطأ والتعبير الشرطي 2 صحيحًا
else:
    العملية عندما يكون التعبيران الشرطيان 1 و2 كلاهما خطأ
```

مثال: برنامج للتقييم بناءً على درجات الاختبار

```python
x = 70                          # تعيين القيمة 70 للمتغير x.
if x >= 90:                     # إذا كانت x تساوي 90 أو أكبر،
    result = 'Grade is A'       # إذا كان الشرط صحيحًا، عيّن "Grade is A" للمتغير result.
elif x >= 50:                   # وإلا، إذا كانت x تساوي 50 أو أكبر،
    result = 'Grade is B'       # عيّن "Grade is B" للمتغير result.
else:                           # إذا لم يتحقق أي من الشروط،
    result = 'Grade is C'       # عيّن "Grade is C" للمتغير result.
print(result)                   # يعرض قيمة المتغير result.
```

نتيجة التنفيذ:

```
Grade is B
```
