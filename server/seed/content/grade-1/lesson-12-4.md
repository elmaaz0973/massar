## النقاط الرئيسية

### معالجة الأخطاء

(هذا عنوان القسم كما هو مطبوع في الكتاب ص 182 وفي الفهرس؛ ومحتوى القسم يشرح القائمة والمصفوفة.)

**القائمة (قائمة)**

**(1) (المصفوفة - list (Array)):** مجموعة من عناصر البيانات مرتبة بالتسلسل. يمكن إدارة البيانات بشكل جماعي.

```python
اسم المصفوفة = [data0, data1, data2, ...]      # تعريف المصفوفة
اسم المصفوفة.append(data)                       # إضافة عناصر إلى نهاية المصفوفة
```

أمثلة (كما في الكتاب):

```python
week = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun']   # مصفوفة سلاسل أحرف
number = [7, 22, 11, 34, 17]                                # مصفوفة أرقام
```

**(2) (العنصر - Element):** كل قيمة مضمنة في مصفوفة. يتيح استخدام (index) (أرقام العناصر) استرداد العناصر من مصفوفة. اسم المصفوفة ورقم مكان العنصر يعرضان العنصر. لاحظ أن index لا تبدأ من 1، ولكن من (0).

**(3) عملية القائمة:** يسمح بإدارة عنصر القائمة باستخدام قوسين مربعين [ ].

مثال: تعريف القائمة وطريقة الوصول إلى العناصر. استخدام متغير داخل القوسين المربعين مثل [i] يجعل من الممكن تحديد العناصر بالمتغير. هذا مناسب عند معالجة العناصر واحدة تلو الأخرى باستخدام عبارة "for".

```python
a = [7, 22, 11, 34, 17]        # تعريف المصفوفة "a" وتعيين قيمة لها.
for i in range(0, 5, 1):       # كرر مع زيادة المتغير i من 0 بمقدار 1 (حتى يتحقق الشرط، أي حتى 4).
    print(a[i])                # يعرض عناصر المصفوفة "a".
```

نتيجة التنفيذ:

```
7
22
11
34
17
```

مثال: إضافة عنصر إلى نهاية مصفوفة أحادية البعد

```python
a = []            # تعريف المصفوفة "a".
a.append(1)       # إضافة (1) إلى نهاية المصفوفة "a".
a.append(4)       # إضافة (4) إلى نهاية المصفوفة "a".
a.append(9)       # إضافة (9) إلى نهاية المصفوفة "a".
print(a)          # يعرض قيم المصفوفة "a".
```

نتيجة التنفيذ:

```
[1, 4, 9]
```

**(4) (مصفوفة ثنائية الأبعاد):** مصفوفة تدير البيانات باستخدام الأقواس المربعة في كل من اتجاهي الصف والعمود. يُحدَّد عنصر في الصف "i" والعمود "j" بكتابة القوسين على النحو التالي: a[i][j].

مثال: تعريف القائمة ثنائية الأبعاد وطريقة الوصول إلى العناصر

```python
a = [['A', 'B', 'C'],
     ['D', 'E', 'F']]    # تعريف المصفوفة "a" وتعيين سلسلة أحرف لها.
print(a[0][0])           # يعرض قيمة العنصر a[0][0].
print(a[1][2])           # يعرض قيمة العنصر a[1][2].
```

نتيجة التنفيذ:

```
A
F
```
