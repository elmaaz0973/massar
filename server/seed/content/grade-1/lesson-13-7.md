## النقاط الرئيسية

في هذا الدرس، سنقوم باستخدام الذكاء الاصطناعي التوليدي لإنتاج كود برمجي لتطبيق ويب بسيط باستخدام لغة JavaScript.

### أسئلة تمهيدية

لنفتح أداة «Copilot» وندخل الأمر التوجيهي التالي:

> «أنشئ تطبيقاً بسيطاً لاختبار من متعدد (Quiz App) يحتوي على سؤال واحد فقط».

- ثم نقوم بلصق الكود الناتج في HTML و CSS و JavaScript داخل أداة WebDen ونقوم بتشغيله.
- (ملاحظة: بما أن الذكاء الاصطناعي ينتج كوداً مختلفاً في كل مرة، فإن هذا مجرد نموذج استرشادي واحد).
- لنقم بتعديل أكواد HTML و CSS و JS لتغيير نص السؤال أو الإجابة.
- لندخل الأمر التوجيهي (prompt) التالي للذكاء الاصطناعي التوليدي واقرأ الشرح: «اشرح هذا الكود».

### حاول بنفسك

لنعطِ الأمر التوجيهي التالي للذكاء الاصطناعي:

> «اجعل الاختبار يتكون من 3 أسئلة».

- لنقم بلصق الكود الناتج في أداة WebDen ونقوم بتشغيله.
- (ملاحظة: نظراً لأن مخرجات الذكاء الاصطناعي التوليدي تختلف في كل مرة، فإن الكود المرفق يُعد نموذجاً استرشادياً واحداً فقط).
- لنقم بتعديل أكواد HTML و CSS و JavaScript لتعديل عدد الأسئلة.
- اطلب من الذكاء الاصطناعي مجدداً: «اشرح هذا الكود».

### تدريب

لنقم بتخصيص تطبيق الاختبار الذي أنشأته، من خلال إضافة الميزات التالية:

- زيادة عدد الخيارات المتاحة لكل سؤال (اختياري).
- عرض نسبة الإجابات الصحيحة (النتيجة النهائية).
- جعل ترتيب الأسئلة يظهر بشكل عشوائي.

صنّف المحتوى الذي لخصته إلى «موضوعات كنت تعرفها» و«موضوعات لم تكن تعرفها»، واسأل الذكاء الاصطناعي لفهمها بشكل أعمق.
