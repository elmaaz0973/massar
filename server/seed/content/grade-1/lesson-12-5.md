## النقاط الرئيسية

### 1. هياكل البيانات

**(1) (الدالة - Function):** مجموعة من العمليات التي يقوم بها جهاز كمبيوتر يوصف بأنها وحدة متماسكة.

- المتغير المحدد ليستقبل قيمة داخل دالة يعرف باسم (وسيطة - argument).
- استخدام (return) يجعل من الممكن تمرير القيمة الناتجة عن العملية داخل الدالة إلى المتصل كـ (قيمة إرجاع - return value).
- عند استخدام دالة، من الضروري إجراء عملية استدعاء للدالة (Function Call).

```python
def اسم_الدالة(Argument 1, Argument 2, ...):
    العملية
    return قيمة الإرجاع
```

(الشكل في الكتاب يوضح: تعريف الدالة (Definition of a Function)، واستدعاء الدالة (Function Call) بتمرير الوسائط (Argument 1, Argument 2, ...)، وقيمة الإرجاع (Return value).)

مثال: مثال على دالة ذات وسيطة واحدة: برنامج للعثور على الدالة y = 2x

```python
def function(x):          # تعريف دالة تسمى function.
    y = x * 2             # تعيين القيمة من x*2 إلى المتغير "y".
    return y              # إرجاع "y" كقيمة إرجاع.
print(function(5))        # تمرير 5 كـ "x" إلى الدالة function.
```

نتيجة التنفيذ:

```
10
```

مثال: مثال على دالة ذات وسيطتين: برنامج للعثور على مساحة المثلث

```python
def area(base, height):   # تعريف دالة تسمى area.
    S = base * height / 2 # تعيين القيمة من base*height/2 إلى المتغير S.
    return S              # إرجاع S كقيمة إرجاع.
print(area(10, 5))        # تمرير 10 كـ "base" و5 كـ "height" إلى الدالة area.
```

نتيجة التنفيذ (كما هي مطبوعة في الكتاب):

```
25
```
