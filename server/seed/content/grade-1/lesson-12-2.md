## النقاط الرئيسية

### 1. المتغيرات والبنية التسلسلية

**(1) (print):** يعرض سلسلة الأحرف أو القيمة داخل الأقواس ( ). سلسلة الأحرف محاطة بعلامات اقتباس مفردة نصف العرض (') أو علامة تنصيص مزدوجة (").

* لاحظ أن القيم الرقمية لا يجب أن تُحاط بعلامات اقتباس.

```python
print('Hello khalid')   # يعرض Hello khalid
print(2023)             # يعرض 2023
```

نتيجة التنفيذ:

```
Hello khalid
2023
```

**(2) (متغير):** مثل مربع لتخزين البيانات. يمكن تخزين البيانات واسترجاعها من المتغيرات.

مثال: برنامج لعرض نص "Cairo"

```python
city = 'Cairo'    # يخصص "Cairo" في المتغير city
print(city)       # يعرض قيمة المتغير "city".
```

نتيجة التنفيذ:

```
Cairo
```

* في البرمجة، لا يعني الرمز "=" "متساوٍ". بدلًا من ذلك، يعني "(تعيين الجانب الأيمن إلى الجانب الأيسر)".

**(3) (معامل التخصيص):** شيء مثل "=" يستخدم لتعيين قيمة إلى متغير.

**(4) (المعامل الحسابي):** رمز مثل "+" و "-" يستخدم في العمليات الحسابية.

| المعامل الحسابي | المعنى |
|---|---|
| a + b | الجمع (Addition) |
| a - b | الطرح (Subtraction) |
| a * b | الضرب (Multiplication) |
| a / b | القسمة (Division) |
| a // b | خارج القسمة (Quotient) |
| a % b | الباقي عندما يُقسم a على b (Remainder) |
| a ** b | a أس b (a to the power of b) |

مثال: برنامج يقوم بأربع عمليات حسابية أساسية (والبقية)

```python
a = 5            # يُعيَّن 5 إلى المتغير a.
b = 3            # يُعيَّن 3 إلى المتغير b.
print(a + b)     # يعرض a + b.
print(a - b)     # يعرض a - b.
print(a * b)     # يعرض a × b.
print(a / b)     # يعرض a ÷ b.
print(a // b)    # يعرض خارج القسمة عندما يُقسم a على b.
print(a % b)     # يعرض الباقي عندما يُقسم a على b.
print(a ** b)    # يعرض a أس b.
```
