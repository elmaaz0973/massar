## النقاط الرئيسية

**HTML (Hypertext Markup Language):** هي اللغة الأساسية المستخدمة لعرض صفحات المواقع عبر متصفحات الويب. تتركز وظيفتها الجوهرية في بناء الهيكل الإنشائي للصفحة، حيث تُستخدم لتحديد العناصر الأساسية مثل العناوين، والجداول، والقوائم.

**CSS (Cascading Style Sheets):** هي اللغة المسؤولة عن شكل وتصميم صفحة الويب ومن خلالها، يمكن التحكم بدقة في التفاصيل الجمالية، مثل أحجام النصوص، وأنواع الخطوط، وألوان الخلفيات.

**الخلاصة:** من خلال الدمج بين HTML و CSS، يمكنك بناء وتصميم صفحات ويب متكاملة وعصرية بشكل عالي الكفاءة.

| اللغة | دورها في الشكل التوضيحي |
|---|---|
| HTML | المحتوى والبنية (Content and Structure): العناوين (Headings)، النص (text)، إلخ |
| CSS | التصميم (Design): لون النص (Text color)، إلخ |

(الشكل في الكتاب: مثال كود HTML ومثال كود CSS يظهران معاً في عرض المتصفح (Browser Display).)

في المثال السابق، تم تحديد لون النص داخل وسوم (tags) الـ `<p>` في لغة HTML ليظهر باللون «الأحمر» باستخدام لغة CSS. فتكمن الميزة هنا في أنه يمكنك تغيير لون النص لجميع الفقرات (وسوم `<p>`) الموجودة في صفحة الويب بالكامل من مكان واحد فقط داخل ملف الـ CSS، دون الحاجة لتعديل كل فقرة على حدة.

### أسئلة تمهيدية

لنبدأ الآن بكتابة صفحة بسيطة لكتابة اسمك (للتعريف بنفسك) باستخدام لغة HTML.

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>About Me</title>
</head>
<body>
<h1>Adam</h1>
</body>
</html>
```

لنقم بنسخ ولصق (أو كتابة) الكود أعلاه داخل موقع https://webden.dev/، ثم اضغط على زر التشغيل (Run). ستظهر لك صفحة بسيطة تعرض الاسم الذي كتبته.

بعد ذلك، سنقوم بتغيير لون النص وحجمه باستخدام لغة CSS.

**كود HTML**

```html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>About Me</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<h1 class="name">Adam</h1>
</body>
</html>
```

**كود CSS**

```css
.name {
  color: blue;
}
```

لنقم بنسخ ولصق (أو كتابة) الكود أعلاه داخل موقع WebDen، ثم نضغط على زر التشغيل (Run). لقد تحول النص إلى اللون الأزرق.

في هذا الكود، يتم تحديد class باسم `class="name"` داخل الـ tag HTML، ويتم تعريف التصميم الخاص بهذا الـ class في الـ CSS. يمكنك تغيير تصميم كل عنصر بشكل فردي حتى وإن كانت الوسوم (Tags) من النوع نفسه.

- لنجرّب تغيير حجم الخط ونوعه.
