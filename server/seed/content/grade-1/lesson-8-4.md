## النقاط الرئيسية

### أ. آلية الإنترنت

**(1) (WWW):** هو نظام يربط عددًا لا حصر له من المحتويات على الإنترنت. يمكن للمستخدمين من خلاله تصفح صفحات الويب التي تجمع بيانات متنوعة، ويُشار إليه عادةً بمصطلح الويب.

**(2) (HTML):** لغة تستخدم لإنشاء صفحات الويب.

**(3) (URL):** يمثل موقع صفحة الويب وطريقة التواصل.

هيكل عنوان URL:

```
https://www.mext.go.jp/index.html
```

| الجزء | يقابل في المثال |
|---|---|
| (اسم المخطط) (اسم البروتوكول) Scheme name, Protocol name | https |
| (اسم المضيف) (اسم السيرفر) Hostname, Servername | www |
| (اسم المؤسسة) Name of organization | mext |
| (نوع المنظمة) Type of organization | go |
| (اسم الدولة) Country name | jp |
| (اسم الملف) File name | index.html |

(في الكتاب: اسم النطاق هو الجزء www.mext.go.jp.)

أمثلة على أنواع المنظمات:

| نوع | معنى |
|---|---|
| gov | وكالة حكومية |
| co | شركة |
| edu | مدرسة (الابتدائية، الإعدادية، والثانوية) |
| ac | جامعة / مؤسسة تعليمية |

أمثلة على رموز الدول:

| رمز | اسم الدولة |
|---|---|
| jp | اليابان |
| eg | مصر |
| kr | كوريا الجنوبية |
| cn | الصين |

**(4) عملية تصفح صفحات الويب**

(الشكل في الكتاب: المستخدم يقول «أنا عايز أوصل لـ www.mext.go.jp».)

1. يستعلم من خادم الـ DNS.
2. يرجّع عنوان الـ IP.
3. الوصول عن طريق عنوان الـ IP إلى خادم الويب.
4. يعرض صفحة ويب.

### ب. آلية البريد الإلكتروني

**(1) البريد الإلكتروني:** نظام لتبادل الرسائل والبيانات مع مستخدمين محددين عبر الإنترنت. عند إرسال بريد إلكتروني، تُستخدم عناوين البريد الإلكتروني (email addresses).

**(2) هيكل عنوان البريد الإلكتروني**

1. **اسم المستخدم (Username):** يحدد المستلم.
2. **اسم النطاق (Domain name):** يحدد خادم البريد الذي يستخدمه المستلم.

```
hanako@example.co.jp
```

| الجزء | يقابل في المثال |
|---|---|
| (اسم المستخدم) Username | hanako |
| (اسم المؤسسة) Name of Organization | example |
| (نوع المؤسسة) Type of Organization | co |
| (اسم الدولة) Country name | jp |

(في الكتاب: اسم النطاق هو الجزء example.co.jp.)

**عملية إرسال واستقبال رسائل البريد الإلكتروني**

1. **(SMTP):** بروتوكول لإرسال رسائل البريد الإلكتروني إلى خادم بريد.
2. **(POP):** بروتوكول يُستخدم لتنزيل رسائل البريد الإلكتروني من خادم وحذفها من الخادم.
3. **(IMAP):** بروتوكول للوصول إلى رسائل البريد الإلكتروني المخزنة على خادم بريد.

(الشكل في الكتاب: المرسل ← «بروتوكول إرسال البريد البسيط» ← خادم البريد الصادر ← «بروتوكول إرسال البريد البسيط» ← خادم البريد الوارد، ثم إلى المستلم: «بوب: نزّل الإيميل من السيرفر وامسحه»، و«بروتوكول الوصول للبريد عبر الإنترنت: اعرض الإيميل على السيرفر».)
