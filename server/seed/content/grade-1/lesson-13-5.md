## النقاط الرئيسية

في هذا الدرس، سنقوم باستخدام الذكاء الاصطناعي التوليدي لبرمجة صفحات ويب ديناميكية (تفاعلية) باستخدام لغة JavaScript.

### أسئلة تمهيدية

افتح منصة Copilot وأعطها الأمر التالي:

> «أنشئ صفحة تعريف بنفسك باستخدام HTML و CSS و JavaScript واجعل لون الخلفية يتغير عند الضغط على زر ما».

- قم بنسخ الكود الناتج ولصقه في WebDen وتشغيله.
- ملاحظة: بما أن الذكاء الاصطناعي ينتج كوداً مختلفاً في كل مرة، فإن هذا مجرد نموذج واحد.
- قم بتعديل أكواد HTML و CSS و JavaScript لتغيير ألوان الخلفية المحددة مسبقاً، أو لزيادة تنوع الألوان المتاحة.

بعد ذلك، جرّب الأمر التالي:

> «لنكتب صفحة إخبارية بسيطة باستخدام HTML و CSS و JavaScript واجعل النص الرئيسي يتغير عند النقر على أحد العناوين».

- قم بنسخ الكود الناتج ولصقه في WebDen وتشغيله.
- (ملاحظة: نظراً لأن أدوات الذكاء الاصطناعي التوليدي تقدم نتائج برمجية متغيرة في كل مرة، فإن الكود المرفق هو نموذج استرشادي فقط).
- لنقم بتعديل الكود الذي أنشأه الذكاء الاصطناعي التوليدي لإضافة المزيد من المقالات، أو لتغيير لون الخلفية بناءً على المقال المعروض.

### حاول بنفسك

- هل استوعبت الكود الذي أنشأه الذكاء الاصطناعي؟
- دوّن الأجزاء غير الواضحة بالنسبة لك وابحث عنها. فمن خلال الذكاء الاصطناعي يمكنك اكتشاف تقنيات تتجاوز معرفتك الحالية.
- استثمر هذه المفاهيم الجديدة لتعميق فهمك البرمجي.

### تدريب

لنحاول إنشاء صفحات ويب تفاعلية لأغراض متنوعة باستخدام الذكاء الاصطناعي التوليدي، مثل:

- تصنيف الرياضات الأكثر شعبية.
- مطاعم موصى بها في [اسم المنطقة].
- تعريف بمدرستك [اسم المدرسة].
- أشهر المعالم السياحية في مصر... إلخ.

> تمارين هذا الدرس (تحدّى معلوماتك، جرّب بنفسك، تمرين) موجودة في الكتاب ص 206. الكويز أدناه مبني على شرح الدرس فقط.
